# GitHub → Render → Tilda

Подготовлены файлы для размещения. Публикация в GitHub, создание платного сервиса и изменение Tilda не выполнялись.

## 1. GitHub

Загрузите содержимое этой папки в репозиторий. Не добавляйте `private/`, `.env`, пароли, локальное окружение и SQLite-журнал. Они исключены в `.gitignore`. Публичные исходные таблицы находятся в `data/` и `dataset/`; при обновлении источников применяется единый проверенный снимок.

## 2. Render

Подключите GitHub-репозиторий как Python Web Service или используйте Blueprint `render.yaml`. Команда сборки: `pip install -r requirements.txt`; запуска: `uvicorn app:app --host 0.0.0.0 --port $PORT`. Health check: `/health`.

Blueprint содержит платный план Starter и постоянный диск 1 ГБ. Плата будет определяться Render при создании; файл сам по себе ничего не приобретает. Для SQLite нужен постоянный диск: `AGRIVOLTAIC_PRIVATE_DIR=/var/data/agrivoltaic`, mount path `/var/data`. Без него записи могут пропасть при переразвёртывании. Масштабирование на несколько экземпляров требует миграции журнала в общую БД.

Задайте `TILDA_ORIGINS` точными адресами опубликованного сайта, например `https://farm.example,https://www.farm.example`. Это проверка отправителя координат. Не используйте `*`. Вставка через iframe не требует CORS. Если позже будет самостоятельная форма Tilda, вызывающая JSON API через fetch, отдельно задайте `CORS_ORIGINS` теми же доменами.

После старта проверьте `/health`, `/calculator`, `/products` и `/weather?lat=45&lon=38&year=2024&start_month=4&end_month=9`. Последний запрос должен вернуть радиацию, среднюю температуру и сумму осадков. В локальной среде живой NASA-запрос завершался сетевой/TLS-ошибкой; успешные фикстурные тесты не заменяют эту проверку.

## 3. Tilda и карта

Вставьте `integrations/tilda.html` в HTML-блок T123. В двух местах замените `https://YOUR-SERVICE.onrender.com` на адрес Render. Пример использует Яндекс Карты JavaScript API 2.1 с русским интерфейсом и iframe калькулятора. Замените `YOUR_YANDEX_MAPS_API_KEY` на свой ключ JavaScript API из кабинета разработчика Яндекса. Ключ подключается на стороне браузера; настройте разрешённые домены сайта в кабинете. Условия и лимиты выбранного тарифа проверяются при подключении API.

API подключается один раз на странице. Если он уже подключён другим блоком, используйте одно согласованное подключение с `coordorder=latlong`. Нажатие ставит или переносит метку. Координаты передаются в порядке широта/долгота. Без действующего ключа полноценная работа карты не проверена; на опубликованной странице проверьте выбор точки, загрузку погоды и расчёт.

Нажатие на карту передаёт `{type:'agrivoltaic:location', lat, lon}` в iframe через `postMessage` с точным origin сервиса. Калькулятор принимает сообщение только от своего родительского окна и разрешённого `TILDA_ORIGINS`, проверяет числовые границы координат, заполняет поля, помечает прежний результат устаревшим и запускает загрузку погоды. Площадь участка пользователь вводит отдельно: нажатие на точку не определяет площадь.

При собственной уже готовой карте сохраните этот протокол сообщения в её обработчике клика. Геометрия солнечной установки не передаётся ни в Tilda, ни в публичный JSON. Внешний вид можно менять в `static/` или позднее заменить iframe собственной формой, работающей с теми же публичными маршрутами.

## Журнал владельца

Варианты и выбор пишутся только на диск Render. Локальный `owner_console.py` не увидит удалённый диск автоматически. Для просмотра перенесите согласованную резервную копию SQLite в отдельный приватный каталог на своём компьютере и задайте его через `AGRIVOLTAIC_PRIVATE_DIR`, либо используйте администрируемое защищённое подключение к серверу. Не скачивайте изменяющуюся SQLite обычным копированием: создавайте копию через SQLite backup API. Не размещайте owner-программу на публичном маршруте Tilda.

Ссылка с идентификатором расчёта позволяет читать только публичные показатели и менять выбор этого расчёта. Для персональных кабинетов нужна отдельная пользовательская авторизация.

Официальные справки: [Render: постоянные диски](https://render.com/docs/disks), [Render Blueprint](https://render.com/docs/blueprint-spec), [Tilda: HTML](https://help.tilda.cc/html), [Яндекс Карты: быстрый старт](https://yandex.ru/dev/jsapi-v2-1/doc/ru/).
